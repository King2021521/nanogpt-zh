## 🎯 超参数设置的理论依据

### 1. 模型容量 (d_model, n_layers)

**数据规模**: 36.7万样本，~1365万字符

**参数量计算**:
```
数据量/参数量比例 = 13,651,099 / 21,880,000 ≈ 0.62
```

**理论依据**:
- 一般建议数据量/参数量比例在 **0.5-2.0** 之间
- 我们的比例 0.62 在合理范围内，**不会过拟合**
- 21.9M参数足够学习诗词的复杂模式

### 2. 序列长度 (max_seq_len)

**数据统计**:
- 平均长度: 37 字符
- 分词后平均: ~22 tokens

**设置依据**:
- 设置为 **128** 可以覆盖 95%+ 的样本
- 比原始的 256 节省 **50% 显存**
- 允许更大的 batch_size

### 3. 批次大小 (batch_size)

**设置为 64 的原因**:
1. **训练稳定性**: 批次越大，梯度估计越准确
2. **训练速度**: 充分利用GPU并行计算
3. **每轮步数**: 367,896 / 64 = 5,748 步/轮，合理
4. **显存占用**: 64 × 128 × 384 ≈ 3.1M tokens，可接受

### 4. 学习率 (learning_rate)

**设置为 5e-4 的原因**:
1. **模型规模**: 21.9M参数，中等规模
2. **批次大小**: 64，较大批次可以用较高学习率
3. **参考**: GPT-2 (117M参数) 使用 2.5e-4，我们的模型更小

**学习率调度**:
```
0 → 2,000步:      线性预热 (0 → 5e-4)
2,000 → 100,000步: 余弦衰减 (5e-4 → 5e-5)
```

### 5. 训练步数 (max_steps)

**设置为 100K 的原因**:

**理论计算**:
```
每个样本被训练次数 = (100,000 × 64) / 367,896 ≈ 17.4 次
```

**经验法则**:
- 小数据集 (<10K): 每个样本训练 50-100 次
- 中等数据集 (10K-100K): 每个样本训练 10-30 次
- 大数据集 (>100K): 每个样本训练 3-10 次

我们的 **17.4 次**在中等数据集的合理范围内。

### 6. Warmup步数 (warmup_steps)

**设置为 2,000 的原因**:
```
warmup比例 = 2,000 / 100,000 = 2%
```

**经验法则**:
- Warmup应占总步数的 **1-5%**
- 我们的 2% 在合理范围内
- 足够稳定训练初期

## 💡 关键建议

### ✅ 推荐做法

1. **使用诗词配置** - `config_poetry.py` 针对数据集优化
2. **GPU训练** - 至少 RTX 3060 或更好
3. **监控验证损失** - 每1000步评估一次
4. **保存多个检查点** - 每2000步保存
5. **使用TensorBoard** - 实时监控训练

### ⚠️ 注意事项

1. **显存管理** - 如果OOM，减小batch_size
2. **过拟合检测** - 如果val_loss上升，提前停止
3. **学习率调整** - 如果不收敛，降低学习率
4. **检查点管理** - 定期清理旧检查点节省空间
