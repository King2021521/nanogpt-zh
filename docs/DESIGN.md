## 六、关键技术要点

### 6.1 Attention机制核心公式
```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

### 6.2 训练技巧
1. **梯度裁剪**：防止梯度爆炸，建议clip_norm=1.0
2. **学习率预热**：前期小学习率，逐步增大
3. **标签平滑**：减少过拟合，smoothing=0.1
4. **混合精度训练**：加速训练（需要支持的GPU）

### 6.3 常见问题和解决方案
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 损失不下降 | 学习率过大/过小 | 调整学习率，尝试1e-4 |
| 显存溢出 | Batch size过大 | 减小batch size，使用梯度累积 |
| 过拟合 | 模型过大或数据过少 | 增加Dropout，扩充数据集 |
| 训练不稳定 | 梯度爆炸 | 使用梯度裁剪，检查初始化 |
