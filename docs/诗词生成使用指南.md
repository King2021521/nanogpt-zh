# 诗词生成使用指南

## 快速开始

### 方法一：使用快速生成脚本（推荐）

最简单的方式，一键测试多个诗词开头：

```bash
python quick_generate.py
```

输出示例：
```
提示: 春江潮水连海平
生成: 春江潮水连海平。海上明月共谁知。

提示: 明月几时有
生成: 明月几时有，把酒问青天。不知天上宫阙，何处是归年。
```

### 方法二：交互式生成

进入交互模式，可以输入任意诗词开头：

```bash
python quick_generate.py interactive
```

然后输入诗词开头，模型会自动续写：

```
请输入诗词开头: 春江潮水连海平
生成中...
生成结果: 春江潮水连海平。海上明月共谁知。
```

### 方法三：使用完整测试脚本

提供更多测试选项：

```bash
# 测试诗词续写（从测试集随机选择）
python test_poetry.py --mode continuation

# 批量测试多个诗词开头
python test_poetry.py --mode batch

# 测试不同温度参数的效果
python test_poetry.py --mode temperature --prompt "春江潮水连海平"

# 完整测试（包括所有测试项）
python test_poetry.py --mode all
```

## 参数调优

### 核心参数说明

| 参数 | 默认值 | 推荐范围 | 说明 |
|------|--------|----------|------|
| `temperature` | 1.0 | 0.8-1.5 | 采样温度，越高越随机，越低越保守 |
| `top_k` | 80 | 60-150 | Top-K采样，保留概率最高的K个词 |
| `top_p` | 0.9 | 0.85-0.98 | Top-P采样，保留累积概率达到P的词 |
| `max_length` | 128 | 64-256 | 最大生成长度 |

### 根据需求选择参数

#### 1. 追求稳定性和连贯性

```bash
python quick_generate.py "春江潮水" 0.9 60
```

或使用测试脚本：

```bash
python test_poetry.py --mode batch --temperature 0.9 --top_k 60 --top_p 0.85
```

**特点**：
- 生成更保守，更接近训练数据
- 连贯性好，错误少
- 适合需要高质量、低风险的场景

**示例输出**：
```
春江潮水连海平，海上明月共潮生。
```

#### 2. 平衡质量和多样性（推荐）

```bash
python quick_generate.py "明月几时有" 1.0 80
```

或：

```bash
python test_poetry.py --mode batch --temperature 1.0 --top_k 80 --top_p 0.9
```

**特点**：
- 默认配置，效果较好
- 质量和多样性平衡
- 适合大多数场景

**示例输出**：
```
明月几时有，把酒问青天。不知天上宫阙，何处是归年。
```

#### 3. 追求创意和多样性

```bash
python quick_generate.py "床前明月光" 1.2 100
```

或：

```bash
python test_poetry.py --mode batch --temperature 1.2 --top_k 100 --top_p 0.95
```

**特点**：
- 生成更有创意
- 多样性高，每次生成结果不同
- 适合需要新颖内容的场景

**示例输出**：
```
床前明月光，疑是地上霜。举头望明月，低头思故乡。
```

#### 4. 极致多样性（实验性）

```bash
python quick_generate.py "白日依山尽" 1.5 150
```

**特点**：
- 生成非常多样化
- 可能出现不太连贯的内容
- 适合探索模型能力边界

## 常见问题

### Q1: 生成的内容太短怎么办？

**解决方案**：
1. 增加 `max_length` 参数：`--max_length 256`
2. 提高 `temperature`：`--temperature 1.2`
3. 增大 `top_k`：`--top_k 100`

### Q2: 生成的内容不连贯怎么办？

**解决方案**：
1. 降低 `temperature`：`--temperature 0.9`
2. 减小 `top_k`：`--top_k 60`
3. 降低 `top_p`：`--top_p 0.85`

### Q3: 生成的内容太保守、缺乏创意怎么办？

**解决方案**：
1. 提高 `temperature`：`--temperature 1.2-1.5`
2. 增大 `top_k`：`--top_k 100-150`
3. 提高 `top_p`：`--top_p 0.95`

### Q4: 如何生成更长的诗词？

**解决方案**：
```bash
python test_poetry.py --mode single --prompt "春江潮水连海平" --max_length 256 --temperature 1.0
```

### Q5: 如何让模型生成特定风格的诗词？

**当前限制**：
- 模型是基础的续写模型，只能根据给定的开头续写
- 不支持指令式生成（如"写一首七言绝句"）
- 如需指令式生成，需要进行指令微调

**替代方案**：
- 提供具有特定风格的开头，模型会尝试延续该风格
- 例如：
  - 七言绝句：提供七字开头
  - 五言绝句：提供五字开头
  - 长诗：提供较长的开头
