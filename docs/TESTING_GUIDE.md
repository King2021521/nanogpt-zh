## 🎯 测试模式

### 模式1: 单个生成测试 (single)

测试单个提示的生成效果，生成多个样本：

```bash
python test_poetry.py --mode single --prompt "春江潮水连海平" --temperature 0.8
```

**参数说明**:
- `--prompt`: 诗词开头
- `--temperature`: 采样温度 (0.5-1.2)
- `--top_k`: Top-K采样 (默认40)
- `--top_p`: Top-P采样 (默认0.85)
- `--max_length`: 最大生成长度 (默认64)

**示例输出**:
```
提示: 春江潮水连海平
------------------------------------------------------------
样本 1:
春江潮水连海平，海上明月共潮生。滟滟随波千万里，何处春江无月明。

样本 2:
春江潮水连海平，海上明月共潮生。江流宛转绕芳甸，月照花林皆似霰。

样本 3:
春江潮水连海平，海上明月共潮生。滟滟随波千万里，何处春江无月明。
```

### 模式2: 批量生成测试 (batch)

测试多个不同的诗词开头：

```bash
python test_poetry.py --mode batch
```

会测试以下经典诗句：
- 春江潮水连海平
- 明月几时有
- 床前明月光
- 白日依山尽
- 独在异乡为异客
- 空山新雨后
- 大漠孤烟直
- 飞流直下三千尺

### 模式3: 温度参数测试 (temperature)

测试不同温度对生成质量的影响：

```bash
python test_poetry.py --mode temperature --prompt "明月几时有"
```

会测试温度值: 0.5, 0.8, 1.0, 1.2

**温度说明**:
| 温度 | 效果 | 适用场景 |
|------|------|---------|
| 0.5 | 保守，重复性高 | 生成格律严谨的诗词 |
| 0.8 | 平衡（推荐） | 日常使用 |
| 1.0 | 标准采样 | 增加多样性 |
| 1.2 | 创新，可能不连贯 | 实验性创作 |

### 模式4: 诗词续写测试 (continuation)

从测试集中随机选择诗词，用前半部分作为提示，生成后半部分：

```bash
python test_poetry.py --mode continuation
```

**示例输出**:
```
样本 1:
提示: 半生长以客为家
原文: 半生长以客为家，罢直初来瀚海槎。始信人间行不尽，天涯更复有天涯。
------------------------------------------------------------
生成: 半生长以客为家，罢直初来瀚海槎。始信人间行不尽，天涯更复有天涯。
```

### 模式5: 困惑度评估 (perplexity)

计算模型在测试集上的困惑度（Perplexity）：

```bash
python test_poetry.py --mode perplexity
```

**困惑度说明**:
- 困惑度越低，模型越好
- 优秀模型: < 10
- 良好模型: 10-20
- 可接受: 20-50
- 需要改进: > 50

**示例输出**:
```
测试样本数: 100
平均损失: 2.1234
困惑度: 8.36
```

### 模式6: 交互式生成 (interactive)

实时与模型交互：

```bash
python test_poetry.py --mode interactive
```

**使用方法**:
1. 输入诗词开头
2. 模型生成3个样本供选择
3. 输入 `config` 查看当前配置
4. 输入 `quit` 或 `exit` 退出

**示例会话**:
```
请输入诗词开头: 明月几时有

生成中...

生成结果:
============================================================

样本 1:
明月几时有，把酒问青天。不知天上宫阙，今夕是何年。

样本 2:
明月几时有，把酒问青天。不知天上宫阙，今夕是何年。我欲乘风归去...

样本 3:
明月几时有，把酒问青天。不知天上宫阙，今夕是何年。人有悲欢离合...
```

## 📊 评估指标

### 1. 困惑度 (Perplexity)

**定义**: 模型对测试数据的预测能力

**计算公式**:
```
Perplexity = exp(average_loss)
```

**评估标准**:
| 困惑度 | 评级 | 说明 |
|--------|------|------|
| < 10 | 优秀 ⭐⭐⭐⭐⭐ | 模型质量很高 |
| 10-20 | 良好 ⭐⭐⭐⭐ | 模型表现不错 |
| 20-50 | 可接受 ⭐⭐⭐ | 基本可用 |
| > 50 | 需改进 ⭐⭐ | 需要更多训练 |

### 2. 生成质量（主观评估）

评估维度：
- ✅ **连贯性**: 生成的诗词是否通顺
- ✅ **相关性**: 是否与提示相关
- ✅ **创造性**: 是否有新意
- ✅ **格律**: 是否符合诗词格律
- ✅ **意境**: 是否有意境美

### 3. 续写准确度

对于续写任务，可以比较：
- 生成文本与原文的相似度
- 是否保持了原诗的风格
- 是否延续了原诗的主题

## 🔍 结果分析

### 好的生成结果特征

✅ **连贯性好**
```
提示: 春江潮水连海平
生成: 春江潮水连海平，海上明月共潮生。滟滟随波千万里，何处春江无月明。
```
→ 语句通顺，意境完整

✅ **符合格律**
```
提示: 明月几时有
生成: 明月几时有，把酒问青天。不知天上宫阙，今夕是何年。
```
→ 对仗工整，韵律和谐

✅ **有创造性**
```
提示: 空山新雨后
生成: 空山新雨后，天气晚来秋。明月松间照，清泉石上流。
```
→ 不是简单重复训练数据

### 需要改进的结果

❌ **重复性高**
```
生成: 春江春江春江春江...
```
→ 降低temperature或增加训练

❌ **不连贯**
```
生成: 春江潮水连海平，床前明月光，白日依山尽...
```
→ 可能训练不足

❌ **不相关**
```
提示: 春江潮水连海平
生成: 我家洗砚池头树，朵朵花开淡墨痕...
```
→ 与提示主题不符

## 🛠️ 常见问题

### Q1: 找不到检查点文件

**错误**:
```
错误: 找不到模型检查点文件
```

**解决**:
```bash
# 检查检查点目录
ls checkpoints_poetry/

# 指定正确的检查点路径
python test_poetry.py --checkpoint checkpoints_poetry/final_model.pt
```

### Q2: 生成结果重复

**原因**: temperature太低或训练不足

**解决**:
```bash
# 提高temperature
python test_poetry.py --mode single --temperature 1.0

# 或增加top_k
python test_poetry.py --mode single --top_k 60
```

### Q3: 生成结果不连贯

**原因**: temperature太高

**解决**:
```bash
# 降低temperature
python test_poetry.py --mode single --temperature 0.6

# 或减小top_p
python test_poetry.py --mode single --top_p 0.75
```

### Q4: 困惑度很高

**原因**: 模型训练不足或测试数据分布不同

**解决**:
1. 继续训练更多步数
2. 检查是否使用了正确的检查点
3. 确认测试数据与训练数据分布一致

### Q5: 显存不足

**错误**:
```
CUDA out of memory
```

**解决**:
```python
# 在test_poetry.py中，减小batch_size
# 或在生成时减小max_length
python test_poetry.py --mode single --max_length 32
```
