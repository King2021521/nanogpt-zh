## 技术细节

### 三个关键优化

1. **抑制EOS token**（核心改进）
   - 在生成前90%步数中降低EOS token概率
   - 避免过早结束生成
   - 文件：`models/gpt.py`

2. **优化生成参数**
   - temperature: 0.8 → 1.0
   - top_k: 40 → 80
   - max_length: 64 → 128
   - 文件：`test_poetry.py`

3. **移除特殊token干扰**
   - 不在输入中添加 `<BOS>` 和 `<EOS>`
   - 减少对生成的干扰

### 参数推荐

| 场景 | temperature | top_k | 说明 |
|------|-------------|-------|------|
| 追求稳定性 | 0.9 | 60 | 保守，连贯性好 |
| 平衡质量和多样性 | 1.0 | 80 | **推荐** |
| 追求创意 | 1.2 | 100 | 多样化，有创意 |

## 常见问题

- 提高 `temperature`

- 减小 `top_k` 到 60

**Q: 想要更多创意？**
- 提高 `temperature` 到 1.2
- 增大 `top_k` 到 100
